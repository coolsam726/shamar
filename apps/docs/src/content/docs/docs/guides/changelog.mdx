Package versions are published on npm under the `@shamar/*` scope. This page is a short history of those releases so you can see what changed between versions. It is not a setup guide. New work starts at [Introduction](/docs/guides/introduction/).

GitHub releases track the monorepo tags.

| Version | Notes |
|---------|--------|
| **0.3.0** | Dashboard widgets, docs screenshots, FilePicker `apiBase` fix. `@shamar/wire@0.3.0` was published later. New Wire versions use npm trusted publishing from `.github/workflows/publish.yml` |
| **0.2.1** | Unified product site: landing + `/docs` + `/demo` panel, 20-minute sandbox reset, single-host deploy |
| **0.2.0** | Rich editor modes, expanded field catalog, SettingsPage, admin UI polish |
| **0.1.x** | Initial public packages — core DSL, Adonis provider, Lucid/Mongoose adapters |

See [GitHub Releases](https://github.com/coolsam726/shamar/releases) for full notes.
