Package versions are published on npm under the `@shamar/*` scope. This page is a short history of those releases so you can see what changed between versions. It is not a setup guide. New work starts at [Introduction](/docs/guides/introduction/).

GitHub releases track the monorepo tags.

| Version | Notes |
|---------|--------|
| **1.0.4** | Schemas docs catalog (Section, Fieldset, Tabs/Wizard H+V, Text, Callout, …). Actions docs expanded to Filament-style depth. `Text` schema component and `Wizard.vertical()`. Notifications: Heroicons bell, unread-only dropdown, View all aside, detail modal marks read, envelope read/unread toggle |
| **1.0.3** | Infolists use form-like horizontal dividers (no gray empty grid). Tickets demo modal CRUD (`quickActions`). Theme menu adds System. Topbar notification demo is obvious (welcome bell + header icons). Marketing demo CTAs point at `demo.shamar.dev`. Cloudflare Worker Previews config for PR builds |
| **1.0.2** | Wire navigate no longer blanks Files/Settings (Alpine parent scope). Global search Wire checksum fix. Full-bleed stat sparklines. Demo notify-self ticket actions. Resource modal quick actions. Docs light/dark screenshots + landing/login theme toggles |
| **1.0.1** | Infolist labels humanize (`assigneeEmail` → Assignee Email). Orbit-style bordered detail entries, ticket confirm dialogs, CardWidget HTML unescape, idle-gated demo reset |
| **1.0.0** | First stable release. Demo panel on a private VPS (GHCR + release deploy). Playground polish: branding defaults, Settings colors, read-only viewer UI, Filament-style infolists, accent navigate loader, multi-panel demo links, media SPA fix |
| **0.4.0** | Wire is the panel runtime (Livewire-style components, SPA navigation). Docs introduce Shamar, Filament, and Livewire. `node ace configure` wires MongoDB when you choose Mongoose. Published through npm trusted publishing (`publish.yml`) |
| **0.3.0** | Dashboard widgets, docs screenshots, FilePicker `apiBase` fix. `@shamar/wire@0.3.0` was published later |
| **0.2.1** | Unified product site: landing + `/docs` + `/demo` panel, 20-minute sandbox reset, single-host deploy |
| **0.2.0** | Rich editor modes, expanded field catalog, SettingsPage, admin UI polish |
| **0.1.x** | Initial public packages — core DSL, Adonis provider, Lucid/Mongoose adapters |

See [GitHub Releases](https://github.com/coolsam726/shamar/releases) for full notes.
