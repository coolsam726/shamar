Package versions are published on npm under the `@shamar/*` scope. This page is a short history of those releases so you can see what changed between versions. It is not a setup guide. New work starts at [Introduction](/docs/guides/introduction/).

GitHub releases track the monorepo tags.

| Version | Notes |
|---------|--------|
| **1.0.19** | ChartWidget Apex/Chart.js pie & donut honor per-slice `colors` / `datasets[].colors` (fixes [#96](https://github.com/coolsam726/shamar/issues/96)). Lockstep all `@shamar/*` to **1.0.19** |
| **1.0.18** | Lockstep republish: every `@shamar/*` at **1.0.18**. Fixes `@shamar/adonis@1.0.17` tarball still declaring exact `1.0.16` sibling deps (published before sibling align) |
| **1.0.17** | Lazy Chart/List/Card widget hydrate + Alpine form/`wire:key` scope fixes (`@shamar/adonis`). Align remaining `@shamar/*` siblings (core, cherubim, lucid, mongoose, rest, wire) to **1.0.17** lockstep |
| **1.0.16** | Custom themes (`ShamarTheme` / Firefly parity), `MaxWidth` + `maxContentWidth`, Wire navigate shell layout sync, REST docs auth, branding topbar tokens, SIDE accordion, list pagination persist, icon multiline, hostEdge via host `createRequire`, theme CSS commands |
| **1.0.15** | Align all `@shamar/*` packages to **1.0.15** (siblings were stuck at 1.0.10 after the 1.0.14 tag). `@shamar/adonis` re-exports `NavigationType` via a local const so JetBrains IDEs resolve `NavigationType.APP` / `.SIDE` / … autocomplete |
| **1.0.14** | `NavigationType` const (`APP`, `APP_INVERSE`, `SIDE`/`SIDEBAR`, `TOP`) for IDE autocomplete from `@shamar/adonis` / `@shamar/core`; string literals still accepted. Mobile always uses a sidebar drawer with accordion groups regardless of desktop navigation type. See [Resource navigation](/docs/reference/resources/navigation/) |
| **1.0.13** | Blade Icons–style Heroicons registry (`heroicon-o/s/m-…`, short names → outline) with extensible `Icons.add` prefixes; stock Edge partials use `iconSvg()`. Firefly-parity panel `navigationType`: `app` / `inverse` / `side` (+ accordion) / `top` (desktop offcanvas + **More** overflow). See [Resource navigation](/docs/reference/resources/navigation/) |
| **1.0.12** | Stop auto-seeding the demo “Welcome to Shamar” topbar notification on every authenticated panel load |
| **1.0.11** | Relation-table edit dialogs no longer save the parent page form by mistake (duplicate `#shamar-form` / Save click handler). Embed forms use `shamar-form-embed` and Alpine `formDataFrom` on submit |
| **1.0.7** | Dialog panels no longer use CSS `transform` for centering, so combobox/select dropdowns position correctly in non-fullscreen create/edit modals |
| **1.0.6** | Desktop admin shell no longer shows a duplicate topbar logo beside the sidebar brand (mobile-only brand uses a dedicated display rule) |
| **1.0.5** | Notification open-envelope icon fix; detail modal opens from the aside. Theme cycles Light → Dark → System via icon click. Global search is icon-first on mobile with Ctrl/Cmd+K focus; mobile topbar shows the logo and moves the active group chip into the page body |
| **1.0.4** | Schemas docs catalog (Section, Fieldset, Tabs/Wizard H+V, Text, Callout, …). Actions docs expanded to Filament-style depth. `Text` schema component and `Wizard.vertical()`. Notifications: Heroicons bell, unread-only dropdown, View all aside, detail modal marks read, envelope read/unread toggle |
| **1.0.3** | Infolists use form-like horizontal dividers (no gray empty grid). Tickets demo modal CRUD (`quickActions`). Theme menu adds System. Topbar notification demo is obvious (welcome bell + header icons). Marketing demo CTAs point at `demo.shamar.dev`. Cloudflare Worker Previews config for PR builds |
| **1.0.2** | Wire navigate no longer blanks Files/Settings (Alpine parent scope). Global search Wire checksum fix. Full-bleed stat sparklines. Demo notify-self ticket actions. Resource modal quick actions. Docs light/dark screenshots + landing/login theme toggles |
| **1.0.1** | Infolist labels humanize (`assigneeEmail` → Assignee Email). Orbit-style bordered detail entries, ticket confirm dialogs, CardWidget HTML unescape, idle-gated demo reset |
| **1.0.0** | First stable release. Demo panel on a private VPS (GHCR + release deploy). Playground polish: branding defaults, Settings colors, read-only viewer UI, Filament-style infolists, accent navigate loader, multi-panel demo links, media SPA fix |
| **0.4.0** | Wire is the panel runtime (Livewire-style components, SPA navigation). Docs introduce Shamar, Filament, and Livewire. `node ace configure` wires MongoDB when you choose Mongoose. Published through npm trusted publishing (`publish.yml`) |
| **0.3.0** | Dashboard widgets, docs screenshots, FilePicker `apiBase` fix. `@shamar/wire@0.3.0` was published later |
| **0.2.1** | Unified product site: landing + `/docs` + `/demo` panel, 20-minute sandbox reset, single-host deploy |
| **0.2.0** | Rich editor modes, expanded field catalog, SettingsPage, admin UI polish |
| **0.1.x** | Initial public packages — core DSL, Adonis provider, Lucid/Mongoose adapters |

See [GitHub Releases](https://github.com/coolsam726/shamar/releases) for full notes.
