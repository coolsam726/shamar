## What you can try

- Admin panel at `/demo` — products, companies, media, settings pages
- File manager + `FilePicker`
- Rich editors (simple / notion / document)
- Roles, permissions, and API keys

## How resets work

Every **20 minutes** the demo:

1. Wipes the Mongo database
2. Re-seeds users, catalog data, and roles
3. Publishes a fresh `nextResetAt` on `GET /demo-status`

Sessions bound to old user ids stop working after a wipe — sign in again with the credentials above.
