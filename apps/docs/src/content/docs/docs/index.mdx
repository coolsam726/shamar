Shamar is an admin panel for AdonisJS. You describe resources in TypeScript. The panel serves the lists, forms, and navigation. Start with [Introduction](/docs/guides/introduction/) if you have not seen how those pieces fit. It explains the host, the database adapters, and what you still own before any install command.

## The panel, section by section

Each section below starts by explaining what the feature is. The pages inside it are the reference: method names, options, and examples.

| Section | What it is |
|---------|------------|
| [Resources](/docs/reference/resources/) | One model, exposed as list, create, edit, and show |
| [Forms](/docs/reference/forms/) | The inputs on create and edit |
| [Tables](/docs/reference/tables/) | The columns, search, and filters on a list |
| [Infolists](/docs/reference/infolists/) | The read-only view of one record |
| [Widgets](/docs/reference/widgets/) | The cards and charts on a dashboard |
| [Actions](/docs/reference/actions/) | Buttons that do something to a record or a selection |
| [Pages](/docs/reference/pages/) | Screens that are not a resource, such as settings |
| [Wire](/docs/wire/) | Live components whose state lives on the server |
| [Auth & RBAC](/docs/concepts/auth/) | Sign-in, then permissions |
| [Media library](/docs/concepts/media/) | Files, folders, and file fields |
