Actions are the Filament-style buttons that run against resources and pages: create a record, open a modal, escalate a ticket, delete a selection, or run a custom header job.

Declare them on a resource with `static resourceActions(actions)`, then handle custom names in `static handleAction(name, records, ctx)`.

```ts
static resourceActions(actions: ActionBuilder) {
  actions.create('New product')
  actions.view()
  actions.edit()
  actions.delete().confirm('Delete this product?')
  actions.bulkDelete()
  actions.row('duplicate', 'Duplicate').icon('copy').ungrouped()
  actions.header('export', 'Export CSV').icon('download')
  return actions
}

static override async handleAction(name, records, ctx) {
  if (name === 'duplicate') {
    // mutate records…
    return { message: 'Duplicated', notification: true }
  }
  if (name === 'export') {
    return { message: 'Export queued', notification: { title: 'Export', body: 'CSV will be ready shortly.' } }
  }
  return null
}
```

## Mental model

| Placement | Where it appears | Typical use |
|-----------|------------------|-------------|
| **header** | List / page toolbar | Create, export, notify |
| **row** | Per-record ⋮ menu (or inline) | View, edit, delete, escalate |
| **bulk** | Selection bar | Delete selected, assign |

Built-in CRUD actions (`create` / `view` / `edit` / `delete` / `bulkDelete`) are wired by the Adonis host. Custom names go through `handleAction`.
