An action is a button that does something to a record, or to a set of records, besides the ordinary save of a form. Create, edit, and delete are built in. An export, a duplicate, or a custom confirmation are actions you add. They are not extra routes you design from scratch: you declare them on the resource, and the panel places them on the page and runs the handler when the button is used.

Placement is the idea that takes a minute. A header action sits above the list ("New", "Export"). A row action sits on one record, usually in the ⋮ menu. A bulk action runs on the checkbox selection ("Delete selected"). The same action builder can register all three, which is why they share one section of the docs instead of three unrelated APIs.

```ts
static resourceActions() {
  return actions((a) => {
    a.create('New product')
    a.view()
    a.edit()
    a.delete().confirm('Delete this product?')
    a.bulkDelete()
    a.row('duplicate', 'Duplicate').icon('copy')
    a.header('export', 'Export CSV').icon('download')
  })
}
```

## Placements

| Placement | Where |
|-----------|--------|
| **header** | List/create toolbar (+ New, Export) |
| **row** | Per-record ⋮ menu (or inline via `.ungrouped()`) |
| **bulk** | Selection bar (Delete selected, …) |
