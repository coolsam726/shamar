import DocApiTable from '../../../../../components/DocApiTable.astro';

`Wizard` + `Step` present a stepped create/edit flow with Previous / Next controls. Layout matches Filament’s wizard: **horizontal** step rail by default, or **vertical** beside the panels.

```ts
import { Wizard, Step, TextInput } from '@shamar/core'

Wizard.make([
  Step.make('Identity').icon('user').schema([
    TextInput.make('name').required(),
  ]),
  Step.make('Details').description('Optional extras').schema([
    TextInput.make('notes'),
  ]),
])

// Vertical step list
Wizard.make()
  .vertical()
  .steps([
    Step.make('Account').schema([/* … */]),
    Step.make('Confirm').schema([/* … */]),
  ])
```

:::note
Wizard navigation is **UI-only** today: the host does not yet gate “Next” on per-step validation. Required fields still validate on final submit.
:::
