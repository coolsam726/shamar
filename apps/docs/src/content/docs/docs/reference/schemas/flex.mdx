`Flex` stacks on small screens and splits horizontally from a breakpoint (default `md`), like Filament’s Flex component.

```ts
import { Flex, Section, TextInput } from '@shamar/core'

Flex.make([
  Section.make('Primary').schema([TextInput.make('name')]),
  Section.make('Meta').schema([TextInput.make('code')]),
])
  .from('lg')

// Or build children via schema():
Flex.make()
  .from('md')
  .schema([
    Section.make('Left').grow(false).schema([/* … */]),
    Section.make('Right').schema([/* … */]),
  ])
```
