import DocApiTable from '../../../../../components/DocApiTable.astro';

`Text` is Filament’s schema `Text` component: static prose that participates in the layout tree (not a form control). Prefer [Placeholder](/docs/reference/schemas/placeholder/) when you need a **labeled** field-like slot.

```ts
import { Text, Section } from '@shamar/core'

Section.make('Help').schema([
  Text.make('Use this panel to review campaign targeting before publish.'),
  Text.make()
    .heading('Retention')
    .content('Records older than 90 days are archived automatically.'),
])
```
