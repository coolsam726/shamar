`Callout` highlights guidance or warnings inside a form or infolist schema.

```ts
import { Callout, Section, TextInput } from '@shamar/core'

Section.make('Checkout').schema([
  Callout.make('Billing note')
    .warning()
    .description('Charges apply after the trial ends.')
    .icon('bell'),
  TextInput.make('plan').required(),
])
```

When there are no nested children, `.description()` is also used as the callout body.
