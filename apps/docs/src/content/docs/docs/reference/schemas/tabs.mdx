`Tabs` + `Tab` organize long forms and infolists into panels. Vertical layout puts the tab list beside the panels (Filament / Orbit parity).

```ts
import { Tabs, Tab, TextInput } from '@shamar/core'

// Horizontal (default)
Tabs.make()
  .tabs([
    Tab.make('General').icon('cog').schema([
      TextInput.make('name').required(),
    ]),
    Tab.make('Billing').badge(2).schema([
      TextInput.make('plan'),
    ]),
  ])
  .activeTab(1)

// Vertical
Tabs.make()
  .vertical()
  .tabs([
    Tab.make('Profile').schema([/* … */]),
    Tab.make('Security').schema([/* … */]),
  ])
```
