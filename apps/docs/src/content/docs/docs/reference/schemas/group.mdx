`Group` is an invisible wrapper — useful when you need a nesting boundary for visibility, spans, or composition without a card or legend.

```ts
import { Group, TextInput } from '@shamar/core'

Group.make().schema([
  TextInput.make('firstName'),
  TextInput.make('lastName'),
])
```
