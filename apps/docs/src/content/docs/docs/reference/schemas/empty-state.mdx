title: EmptyState
description: Empty / placeholder block inside a schema.
---

import DocApiTable from '../../../../../components/DocApiTable.astro';

`EmptyState` shows a heading (and optional description) when a region has nothing to display — useful in nested schemas and relation-heavy forms.

```ts
import { EmptyState, Section } from '@shamar/core'

Section.make('Attachments').schema([
  EmptyState.make('No files yet')
    .description('Upload documents after the record is created.')
    .icon('inbox'),
])
```
