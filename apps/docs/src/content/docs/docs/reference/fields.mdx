Common builders from `@shamar/core` (also re-exported patterns in host docs):

| Builder | Notes |
|---------|--------|
| `TextInput` | Text, email, url, password, numeric, textarea |
| `Select` / `Radio` / `Checkbox` / `CheckboxList` / `Toggle` | Choices |
| `DatePicker` / `DateTimePicker` / `TimePicker` / `WeekPicker` / `MonthPicker` | Flowbite pickers (`.native()` available) |
| `FilePicker` | Media library integration |
| `RichEditor` | `.simple()` / `.notion()` / `.document()` |
| `MarkdownEditor` / `CodeEditor` | Authoring |
| `TagsInput` / `KeyValue` / `Repeater` | Structured data |
| `ColorPicker` / `Slider` / `Rating` | Compact widgets |
| Relation fields | BelongsTo / manyToMany / RelationTable |

Hydration is type-aware via the field registry — prefer these builders over ad-hoc controllers.
