---
title: Packages
description: Map of @shamar/* packages in the monorepo.
---

| Package | Role |
|---------|------|
| `@shamar/core` | DSL: resources, forms, tables, pages, validation |
| `@shamar/adonis` | Provider, routes, Edge admin UI, auth login publish |
| `@shamar/lucid` | SQL adapter |
| `@shamar/mongoose` | MongoDB adapter |
| `@shamar/cherubim` | Abilities, policies, API credentials |
| `@shamar/rest` | OpenAPI document + Scalar |

Install what your host app needs; playground wires all of them for the [live demo](/docs/guides/live-demo/).
