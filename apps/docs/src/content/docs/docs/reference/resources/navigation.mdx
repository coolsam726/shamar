## Resource / page fields

```ts
static override navigationGroup = 'Content'
static override navigationSubGroup = 'Catalog'
static override navigationSort = 10
/** Short name or full Blade-icons id (`heroicon-o-…`, `heroicon-s-…`, `heroicon-m-…`). */
static override icon = 'heroicon-o-cube'
// static override icon = 'cube'  // same as heroicon-o-cube
static override navigationHidden = false
```

Navigation items are merged with [Pages](/docs/reference/pages/) and media library entries.

Icons resolve through Shamar’s Blade Icons–style registry (Heroicons by default). Short names become `heroicon-o-{name}`. Full ids keep their stack prefix. Register another set later with `Icons.add('fontawesome', { prefix: 'fas', path: '…' })` for names like `fas-user`.

## Panel navigation type (Firefly parity)

```ts
import { panel } from '@shamar/adonis'

panel('admin')
  .navigationType('app') // default: L1 groups in sidebar; active children in top bar
  // .navigationType('inverse') // or 'app_inverse' — L1 on top; children in sidebar
  // .navigationType('side').navigationAccordion() // full tree in sidebar (accordion)
  // .topNavigation() // full tree in top bar; More packs overflow; no desktop sidebar
```

| Type | Level 1 | Levels 2–3 |
|------|---------|------------|
| `app` (default) | Sidebar | Top bar (active L1 children; nested = dropdowns) |
| `inverse` / `app_inverse` | Top bar | Sidebar |
| `side` | Sidebar (groups as headings; optional accordion) | Sidebar |
| `top` | Top bar (groups as nested dropdowns) | Top bar |

On narrow screens the top item row is hidden and the hamburger opens a drawer with the full tree. When the top-bar row overflows, trailing menus move under **More**.
