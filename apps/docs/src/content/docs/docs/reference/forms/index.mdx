```ts
static form() {
  return form((f) => {
    f.schema([
      Section.make('Basics').schema([
        TextInput.make('name').required(),
      ]),
    ])
  })
}
```

Resources declare a `form()` builder. The Adonis host renders create/edit, hydrates payloads via the **field registry**, and validates required fields.
