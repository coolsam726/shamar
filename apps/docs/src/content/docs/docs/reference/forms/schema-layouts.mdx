Form and infolist **layout chrome** lives under **[Schemas](/docs/reference/schemas/)**:

| Component | Docs |
|-----------|------|
| Section | [Section](/docs/reference/schemas/section/) |
| Fieldset | [Fieldset](/docs/reference/schemas/fieldset/) |
| Grid / Group / Flex | [Grid](/docs/reference/schemas/grid/), [Group](/docs/reference/schemas/group/), [Flex](/docs/reference/schemas/flex/) |
| Tabs (H / V) | [Tabs](/docs/reference/schemas/tabs/) |
| Wizard (H / V) | [Wizard](/docs/reference/schemas/wizard/) |
| Callout / Text / Placeholder / EmptyState | [Callout](/docs/reference/schemas/callout/), [Text](/docs/reference/schemas/text/), [Placeholder](/docs/reference/schemas/placeholder/), [EmptyState](/docs/reference/schemas/empty-state/) |

```ts
import { Section, Grid, Tabs, Tab, Wizard, Step, Fieldset, Callout, Text } from '@shamar/core'

Section.make('Catalog').columns(2).schema([
  Grid.make(2).schema([/* fields */]),
  Text.make('Static guidance in the same tree.'),
])
```

Field controls remain under [Forms](/docs/reference/forms/).
