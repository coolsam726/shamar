Shamar admin panels run on **@shamar/wire**. Filament panels sit on Livewire; Almasix Orbit sits on Conduit; a Shamar panel sits on Wire.

The package is the kernel: signed state, HTML islands, and a small browser runtime. [`@shamar/adonis`](/docs/reference/packages/) is the host. Installing the Adonis package installs Wire and serves it on every panel. You do not register a second provider.

Alpine still owns the older islands (`x-data`, `live()` fields, the form-state POST). A region moves to Wire when its markup uses `wire:*`. Both can sit on the same page.

## Lifecycle

```text
Edge render  →  signed island in the HTML
user input   →  POST {panel}/wire  { snapshot, updates, calls }
server       →  verify checksum, run hooks and methods, re-render
browser      →  morph the island, or follow effects.redirect
```

The panel route is `POST /admin/wire` when the panel path is `/admin`. It requires the same session as the rest of the panel and answers with JSON. The script is `GET /admin/assets/wire.js`, loaded by the admin shell.

Each island is one element:

```html
<div wire:id="…" wire:snapshot="…" wire:endpoint="/admin/wire">
  …
</div>
```

`wire:snapshot` holds the public data and an HMAC. The browser sends it back unchanged. The server rejects a body whose checksum does not match, and it ignores data keys that the component did not declare.

## A component

Public state lives on `data`. Methods on the object are the actions. `create()` runs on every request; anything you need on the next request belongs on `data`.

```ts
import { WireKernel, type WireComponent } from '@shamar/wire'

class Counter implements WireComponent {
  data = { count: 0 }

  increment(): void {
    this.data.count = Number(this.data.count) + 1
  }
}

const kernel = new WireKernel(secret, {
  counter: {
    create: () => new Counter(),
    render: (component) =>
      `<button type="button" wire:click="increment">${component.data.count}</button>`,
  },
})

const { html } = kernel.mount('counter', '/admin/wire')
```

`@shamar/adonis` re-exports `WireKernel`, `WireComponent`, and `WireRequest`, so panel code can import them from either package.

### Hooks

| Hook | When |
|------|------|
| `updating(key, value)` | Before the new value is written |
| `updated(key)` | After the value is written |
| `updatedQuery()` | After the `query` property changes |

Hooks may be async. A thrown error fails the POST; the island on the page is left as it was.

Methods are called after property updates. Names that start with `_`, and the reserved names `data`, `updated`, `call`, `constructor`, `hydrate`, `dehydrate`, and `render`, are not callable from the browser.

### Redirects

Set `this.effects = { redirect: '/admin/orders/4' }` inside a method. The browser navigates there. The effect is not written into the snapshot.

## Templates

| Attribute | What it does |
|-----------|----------------|
| `wire:model="title"` | Remember the value and send it with the next action |
| `wire:model.live="title"` | Send on each input |
| `wire:model.blur="title"` | Send when the field blurs |
| `wire:model.debounce.250ms="query"` | Send after 250ms without further input |
| `wire:click="save"` | Call `save` |
| `wire:click="remove('draft')"` | Call with arguments. Quotes, numbers, `true`, `false`, and `null` keep their types |
| `wire:submit="save"` | On a form. Stops the browser submit and calls `save` |
| `wire:keydown.enter="save"` | Call when Enter is pressed in that element |
| `wire:loading` | Shown only while this island has a request in flight |
| `wire:loading.remove` | Hidden while a request is in flight |
| `wire:ignore` | Skip this element when the island is morphed |
| `wire:key` | Keep a child node across renders (lists, rows) |

The morph updates the existing DOM. The focused input keeps its caret. Children marked `wire:ignore` are left untouched. A nested `wire:id` is its own island and is not rewritten by its parent. New elements are handed to Alpine via `Alpine.initTree`.

### `$wire`

Inside an island, Alpine’s `$wire` magic talks to that island:

```html
<button type="button" x-on:click="$wire.increment()">Add</button>
<span x-text="$wire.count"></span>
```

`$wire.count = 3` and `$wire.$set('count', 3)` post an update. `$wire.increment(1)` and `$wire.$call('increment', 1)` post a call. Reading `$wire.count` returns the value from the snapshot currently in the DOM.

## What the panel uses today

The top-bar search is a Wire island named `global-search`.

- The input is `wire:model.debounce.250ms="query"`.
- On `updated('query')` the server lists up to five records from each navigable resource that has searchable fields, and returns at most eight links.
- A resource the current user cannot view is skipped. One resource failing the query does not clear the rest.

Further panel UI moves onto Wire one island at a time. `live()` fields stay on `POST {panel}/{slug}/form-state` until that form is moved.

## Signing and secrets

The checksum is HMAC-SHA256 of the island id, the component name, and a canonical encoding of `data`. Changing any of those in the browser fails verification.

Pass a stable application secret into `WireKernel`. The global-search host currently uses a secret generated when the process starts, so a restart invalidates islands already open in a tab. The next full page load mounts a new one.

Escape any record text you place in `render()` with `escapeHtml` and `escapeAttr` from `@shamar/wire`.

Package reference, helpers, and the test suite live in `packages/wire/README.md`.
