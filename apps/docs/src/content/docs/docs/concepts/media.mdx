Enable media on a panel to get a File Manager UI and `FilePicker` form fields.

<DocScreenshot
  src="/screenshots/media-library.png"
  alt="Media library with folder tree and file grid"
  caption="File Manager — folders, uploads, visibility, and public URLs. Open `/demo/media` in the live sandbox."
  wide
/>

```ts
panel('admin').media({
  label: 'Files',
  // Omit navigationGroup (or set '') for a top-level sidebar root.
  // navigationGroup: 'System', // nest under an existing cluster
  navigationIcon: 'folder', // also: files, media, photo, image, images
  // disk / adapter / storage options per host docs
})
```

```ts
import { FilePicker } from '@shamar/core'

FilePicker.make('logoMediaId')
  .image()
  .makePublic()
  .label('Logo')
```

Adapters under `@shamar/mongoose` / `@shamar/lucid` persist folders and files; public URLs can power login branding overrides.
